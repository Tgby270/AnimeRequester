# 🎌 AnimeRequester

A lightweight, browser-based web app for requesting and browsing anime titles. powered by the **AnimeDB API** via RapidAPI Built with vanilla HTML, CSS, and JavaScript — no frameworks, no build tools, just open and go.

---

## 📁 Project Structure
```
AnimeRequester/
├── index.html        # Main entry point
├── js/               # JavaScript logic
└── style/            # CSS stylesheets
```

---

## 🚀 Getting Started

### Prerequisites

No dependencies or installs required. Just a modern web browser.

### Running Locally

1. **Clone the repository**
```bash
   git clone https://github.com/Tgby270/AnimeRequester.git
   cd AnimeRequester
```

2. **Open in your browser**

   Simply open `index.html` in any modern browser
